# 指定版式的公文 Word 排版

用于已起草正文的排版与交付；内容写作沿用 `official-document-writing`。当前用户明确的本次格式要求优先。默认不改写事实、数字、标点或编号，不自动添加红头、文号、日期和落款。

## 默认版式

- A4；上下左右页边距均为25mm；所有段落固定行距28磅，段前段后0。
- 文章标题：方正小标宋_GBK，20磅，居中；标题前空一行，标题后空一行再排正文或主送机关。
- 一级标题：方正黑体_GBK，三号16磅，不额外加粗。
- 二级标题：方正楷体_GBK，三号16磅，加粗。
- 三级标题：方正仿宋_GBK，三号16磅，加粗；不另起一行，与其后正文同段接排。段落采用正文格式（两端对齐、首行缩进2字符、固定28磅行距），仅标题文字保持加粗。
- 正文中文：方正仿宋_GBK，三号16磅，常规；两端对齐，首行缩进2字。
- 各层级中的英文、数字及ASCII符号（含%）用Times New Roman，字号和加粗跟随所在段落；中文标点使用相应中文字体。
- 一级、二级标题及正文：首行缩进2字符；三级标题所在段落也按正文首行缩进2字符。正文取消孤行控制。
- 双引号（中文“ ”或英文直引号）及其中内容跟随所在标题或正文的字体、字号和加粗；引号符号本身使用所在位置的中文字体，英文和数字使用 Times New Roman。同段标题与正文交界处分别使用各自格式；不转换或改写原文引号。引号必须在同一段落内配对，否则报告并请用户核实。
- 页脚居中，形式为“— 1 —”“— 2 —”；全部页码字符用四号（14磅）宋体，使用自动PAGE域。重新打开、打印或更新域后由Word/WPS计算页码。
- 同一篇稿件的草稿、过程稿和最终稿放在同一目录。默认目录为 `E:\AI\公文输出\<文稿标题>\`，也可使用用户指定路径。目录名须安全处理Windows文件名禁用字符、尾部空格和点，避免空名、保留名及路径穿越。若目录或目标文件已存在，不覆盖，改用不冲突的名称。
- 写入前确认目标路径；不得绕过 Cherry Studio、操作系统或 Agent 的权限限制。写入失败时说明原因并请用户提供可用路径，不要静默改存到其他位置。

## 环境与脚本

- 本技能包的 `scripts` 子目录包含：
  - `read_docx_text.py`（读取任意已有 `.docx` 的正文与表格文字，不受空行、页眉页脚、自动编号或表格限制）
  - `format_document.py`（从 Markdown/JSON 新建标准方正版式 DOCX）
  - `preserve_docx.py`（对已有 DOCX 进行保结构排版整理）
  - `import_document.py`（新建文档生成过程中的原文比对辅助模块）
- 运行环境要求 Windows、Python 3.10+、`python-docx` 和 `lxml`；字体须已安装在操作系统中。
- 当用户上传或指定了 `.docx` 素材需要读取正文，或需要将该 Word 重新按标准公文版式排版时：
  - 先用 Cherry Studio 内置【文件转 Markdown】工具，或运行 `py -3 "<技能目录>\scripts\read_docx_text.py" --input "<Word路径>"` 读取全文内容（不要直接用 `format_document.py --input xxx.docx` 读取含空行、页眉页脚的日常 Word，否则会因严格结构限制报错）。
  - 若要完整套用标准公文版式（A4、25mm边距、方正四款字体、28磅行距、页码），将读取出的正文整理为受控 UTF-8 Markdown（`# 主标题`、`## 一级标题` 等，不改写原文事实文字），再用 `format_document.py --input 草稿.md --output 成稿.docx` 生成。
  - 若要保留原 Word 的表格、页眉页脚和分节结构仅刷段落字体，才调用 `preserve_docx.py`。
- 执行脚本前，先确认当前 Agent 有本地命令执行能力、可访问源文件和目标目录，并能定位本技能的实际安装目录。技能说明本身不会授予这些权限。
- 如果 Agent 没有本地命令/文件工具，或无法访问技能目录，只提供可复制的 PowerShell 命令和输入文件内容，说明需要用户在本机执行；不得声称已生成或检查文件。
- 不要未经用户同意安装 Python 包或更改系统环境。依赖缺失时，报告缺项并请求用户确认安装。
- 文档字体：方正小标宋_GBK、方正黑体_GBK、方正楷体_GBK、方正仿宋_GBK、Times New Roman、宋体。缺失字体可能导致Word/WPS替换字体，须说明，不自行更换用户指定字体。

## 执行

1. 先按上述规则确定稿件目录。使用UTF-8 Markdown或JSON作为新建文档的输入。Markdown第一行为 `# 文章标题`，标题层级使用 `## 一、一级标题`、`### （一）二级标题`、`#### 1.三级标题`；空行分隔自然段，单换行表示同段内换行。标题编号由原文提供，脚本不编造。不要输出Markdown加粗标记、代码块、表格、图片或链接语法。
2. 同段混排标题与正文可用JSON的 `{"type":"heading2","heading":"（一）标题。","body":"正文"}` 表达；标题与正文须与原文完全一致，不插入空格或标点。署名、日期、主送机关等可使用JSON blocks，类型包括 `recipient`、`body`、`heading1`、`heading2`、`heading3`、`signature` 和 `date`。
3. 对新建DOCX，调用脚本时把 `<技能目录>` 替换成实际技能目录，把输入、输出改成确认过的绝对路径：

   ```powershell
   py -3 "<技能目录>\scripts\format_document.py" --input "E:\AI\公文输出\<文稿标题>\草稿.md" --output "E:\AI\公文输出\<文稿标题>\成稿.docx"
   ```

   脚本默认不覆盖已有输出，输入与输出不能是同一路径。除非用户明确同意，不添加 `--overwrite`。脚本会输出JSON验证结果并自动比对原文。可额外运行：

   ```powershell
   py -3 "<技能目录>\scripts\format_document.py" --check "E:\AI\公文输出\<文稿标题>\成稿.docx" --input "E:\AI\公文输出\<文稿标题>\草稿.md"
   ```
4. 一次性格式覆盖可传 `--config-json`，例如 `'{"line_spacing_pt":30,"styles":{"body":{"font":"宋体","size_pt":16}}}'`；支持四边 `*_margin_mm`、`latin_font` 及各段样式的 `font`、`size_pt`、`bold`。复检时必须提供相同配置；不得静默读取目录中的配置。
5. 已有DOCX使用保结构脚本，并写入新文件，不覆盖原稿或已有文件：

   ```powershell
   py -3 "<技能目录>\scripts\preserve_docx.py" --input "E:\资料\原稿.docx" --output "E:\AI\公文输出\整理后.docx"
   ```

   先依据原稿样式与明确的大纲信息识别标题，不能盲目将普通编号断定为标题。保结构模式不支持页边距覆盖；显式传入会报错。
6. 保结构脚本返回后逐项检查 `status`、`formatted`、`skipped`、`preserved`、`verification` 和 `limitations`。`status` 为 `no_changes` 表示没有完成任何段落排版；未处理或有歧义的段落须向用户说明，不能声称整篇均已排好。验证失败不得交付。
7. 新建文档的检查会核对格式并逐段比对解析后的标题、正文文字和顺序，包含数字、标点和混排文字。此检查不验证内容真实性，也不证明Word/WPS的实际分页完全一致。保结构脚本的结构核验不等同于视觉排版检查。
8. **严禁调用后台 Word/WPS 进程或预览渲染工具打开已生成的 DOCX**：
   - 切勿使用 `New-Object -ComObject Word.Application`、`KWPS.Application`、LibreOffice 或任何后台预览/转换脚本去打开生成的 `.docx` 做分页统计或导出 PDF 预览！Windows 下后台 COM 进程极易残留并死死锁住 `.docx` 文件（导致用户双击打开时报错被进程占用）。
   - 所有格式与内容核验一律仅通过 `format_document.py --check` 或纯 Python `python-docx` 读取完成（读取后立即关闭文件流，不留任何后台进程）。
   - 严禁在用户的公文输出目录（`E:\AI\公文输出\<文稿标题>\`）中生成或遗留 `.py`、`.ps1` 等临时脚本文件，保持公文输出目录整洁。交付时直接向用户报告脚本验证结果即可，实际分页由用户在 Word/WPS 中打开查看。

## 已有文档保结构排版的边界

保结构脚本保留原稿纸张、分节、页眉页脚及页码，不保证符合新建文稿的页面和页码默认值；表格、图片、复杂对象以及不安全的段落按报告保留原样或跳过。不能通过新建文档脚本重建已有DOCX。DOC/WPS自动转换未启用，请用户先另存为DOCX副本。
